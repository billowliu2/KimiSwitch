# KimiSwitch v0.9.0

Kimi Code 2.5.x 适配版，同时完善插件市场、子代理模型池与全局设置体验。

## Kimi Code 2.4 / 2.5 适配

- 会话与工作区管理适配 `projects.json` 注册表、`wm_<uuid>` 工作区及删除标记；旧版 `workspaces.json` 仍作为兼容回退
- 子代理模型配置适配 `[secondary_model] default_model`，保留旧 `model` 键读取；用量计价兼容 2.5.0 直接记录真实模型别名的新行为
- 后台任务配置迁移到 `[task]`，兼容合并旧 `[background]`；补充任务超时、退出保活、print 模式等设置
- 新增工作区信任、会话数据库全文搜索、MCP 重连退避与 Read 字符额度设置；默认值不重复写入配置，保留未建模字段
- 适配 2.5.0 子代理模型池语义，提示并清理已失效的 `force` 与模型补丁字段；单条目模型池固定所有子代理时给出明确说明

## 插件市场

- 适配 2.5.0 catalog 的 `distribution.category`、客户端与平台字段，同时兼容旧 catalog
- 插件卡片展示支持平台；当前系统不受支持时禁用安装并说明原因
- 完善已安装、官方与社区插件分组及安装、更新、启用、禁用和移除操作入口
- 设置页导航合并为一组：全局设置 → 高级设置 → 插件市场 → 关于；移除重复的子代理模型标签，模型配置继续保留在高级设置中

## 其他

- 更新内置 models.dev 模型参考数据
- 补充 Kimi Code 2.5.x 版本状态、配置读写与工作区迁移相关测试
