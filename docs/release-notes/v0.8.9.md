# KimiSwitch v0.8.9

OpenDesign Go 预设 + Command Code GOAT 用量补强版。

## OpenDesign Go 预设（新增）

- 预填 OpenDesign 的 `amr-link` 推理网关（OpenAI 兼容，Bearer API Key）
- 内置 12 个模型映射：DeepSeek V4.1 Flash / V4 Flash / Vision Exp / Pro、Claude Haiku 5.5、GPT-6 Luna、GLM-5.3 Flash / Flash-X、Kimi K2.7 Code、MiMo V2.6 Flash / Pro、Hunyuan H4 Preview
- 预设补齐 OpenDesign 官方品牌图标，卡片与预设选择器不再回退显示首字母
- **用量查询边界**：OpenDesign 的额度窗口仅对本机 `vela` CLI 桌面登录态开放，没有公开 HTTP 查询端点；本版如实隐藏用量行，不伪造查询结果

## Command Code GOAT 用量补强

- credits 接口返回 `windowLimits.monthly` 时，新增月度窗口占比行，与余额、5 小时、每周窗口并列展示
- 月度窗口缺失或 `cap` 非正时静默跳过，不影响既有三行数据
- 预设补齐 Command Code 官方绳结品牌图标，不再回退显示 `CC` 首字母
