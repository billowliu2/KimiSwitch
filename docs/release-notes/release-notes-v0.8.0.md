# KimiSwitch v0.8.0

## 新功能

- **模型映射表新增「最大输出 Token」列**（Kimi Code）：为每个模型单独设置 `max_output_size`，写入 config.toml 的 `[models."<alias>"]`，留空则用上游默认值。models.dev 收录了该模型的输出上限时，输入框下方显示可点击的参考值（如 `参考 128000`），一键填入；「获取模型列表」添加模型时也会自动预填参考值
- **models.dev 快照新增 output 上限字段**：内置快照同步至 2026-10-03（8,385 模型 / 226 供应商，97.4% 模型带 output 上限）；应用内「同步 models.dev」（Rust 侧）同步支持该字段，同步后参考值不丢失

## 修复

- **移除无效的「声明支持 1M」复选框**（Kimi Code）：该控件在读取时由上下文长度派生、写入时不持久化，勾选永远不会生效，已由「最大输出 Token」列取代
