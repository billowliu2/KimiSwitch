# KimiSwitch v0.9.1

Kimi Code 2.8.x 适配版：在 v0.9.0 的 2.5.x 支持基础上，补齐新版会话、工作区、用量与模型配置，同时保留旧格式和既有插件市场能力。

## 会话与工作区

- `state.json` 的 `createdAt` / `updatedAt` 支持数字时间戳与旧字符串格式，统一输出 RFC3339；工作目录优先读取 `cwd`，旧 `workDir` 回退
- 归档与恢复仅修改元数据，不移动会话目录；旧物理归档目录 `.kcd-archive/` 继续兼容
- `projects.json` 作为工作区权威来源，旧 `workspaces.json` 回退；支持名称、root、创建时间与最近打开时间
- 删除空工作区时同步两个注册表及对应删除标记，损坏的 `projects.json` 不会被空配置覆盖

## 用量统计

- `usage.record` 的 `turn` / `session` / `prediction` 三种真实请求各统计一次
- 缺失 `usageScope` 按 `turn` 处理，未知 scope 安全跳过
- 历史 `__secondary__` 副模型记录继续单独归类；新版记录按真实模型别名统计，不用 `agentId` 猜测副模型

## 模型配置

- 支持 `provider_id` / `name` / `aliases` 的导入、编辑与 TOML 往返，身份优先级与上游一致
- 新版身份模型不再被强制写入空的 `provider` / `model`；空身份字段也能保持原始形状
- `overrides` 展示实际生效值，被覆盖字段只读，避免保存后仍被覆盖值遮蔽
- 默认模型、供应商切换、重命名、复制、删除、保存校验与 models.dev 查询均接入新版身份

## Bedrock 与实验开关

- 新增 `type = "bedrock"` 类型识别与配置往返；不包含 AWS 专用模型发现、连通性检查或凭据界面
- 实验开关同步为 `wait_for` / `worktree` / `auto_review` / `notify_user` / `tower` / `prompt_prediction`
- 移除已失效的 `tool-select` 与 `subagent_fork`，同步环境变量探测和中英文说明

## 版本状态

- `2.0.2`–`2.8.1`：`current`
- `2.8.2` 及更高版本：默认 `unknown`，不再自动误报完全适配

- 前端 217 项测试通过
- Rust 253 项测试通过
- `check-version.sh v0.9.1` 通过
- KimiCode 2.8.0 与源码/本机 2.8.1 的 `doctor config` 均通过
- 隔离 GUI 验证供应商切换、会话元数据与归档/恢复、三种用量加历史副模型、模型身份与 overrides 只读展示
