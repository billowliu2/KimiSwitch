# KimiSwitch v0.8.5

设置界面重构版：原来那个塞满所有选项的「设置」弹窗变成了一整页带返回头的全局设置页面，按「全局设置 / 高级设置 / 关于」分页；同时修掉两处体检与更新下载的哑火问题。

## 设置弹窗改为全局设置页面（重构）

- **弹窗改成页面**：原 `SettingsModal` 只能在弹窗那一小块区域里滚动，选项一多就要反复上下翻。现在从右上角齿轮或顶部导航进入的是一整页设置，与「供应商 / 仪表盘 / 会话」平级、由顶部导航直接切换，宽度与上下文都充裕
- **三个 Tab 各管一摊**：
  - **全局设置**——写回 `config.toml` 的代理设置，思考开关与五档思考等级、循环控制（单步最大尝试次数、上下文预留、压缩重试上限）、权限规则、钩子
  - **高级设置**——KimiWebUI、models.dev 参考数据同步/回滚、子代理模型池、实验功能开关
  - **关于**——外观三态（浅色 / 深色 / 跟随系统）、语言、更新检查、kimi-code CLI 版本核验、关于信息
- **「高级设置」入口移入顶部导航组**：此前要从页面底部 footer 的按钮进；现在和「供应商 / 仪表盘 / 会话」并排，位置固定好找
- **代理设置单一入口**：供应商编辑页里内嵌的那份代理设置已移除，全局设置页是唯一入口，不会出现两处各写一半的困惑
- **旧 `view=subagent` 路由保留**：作为兼容外壳继续存在，书签或内部跳转不会失效
- **Tab 切换不丢状态**：非活动面板只是隐藏而非卸载，更新下载的进度与安装包路径在切 Tab 之间保持不丢

## 一键体检：账单缺口修复

- **配了 NewAPI / Sub2API 查询模板但没勾 usageKinds 的供应商不再被静默跳过**：这两条模板路径直接查网关自己的用量端点，本来就不走 `usageKinds`，此前体检却因为它为空而判定「不需要查账单」，把这一行整个漏掉
- **用户在配置面板里主动关掉用量查询时仍然不查**：关掉是明确意图，不该被记成失败项
- 其余情况（无配置、`auto` 模板 + 空 kinds）行为不变，仍不发起账单请求

## 更新下载修复

- **release 没有当前平台安装包资产时，「下载」按钮回退为打开 release 页面**：此前 `downloadUrl` 缺失就静默返回，点了没反应像是按钮坏了；现在直接跳 release 页，用户可自行选资产。连 release 页地址都没有时才提示原因
- **自动更新过滤 draft 与 prerelease**：两个托管站都按「最新在前」返回，此前直接取数组第一个；若最新一条是 draft，或正式版之后又发了一个 rc，就会被当成更新推给用户。现在显式跳过未发布与预发布，取最新的正式版，全被过滤掉时按「无已发布版本」处理而不是 panic

## 其他

- **启动瞬间的色差修复**：CSS 变量默认深色，而 Tailwind 的 `dark:` 变体要等 React 挂载后才生效，启动瞬间激活的供应商卡片会先闪一下浅色；现在 `index.html` 首帧前内联脚本即按 localStorage + 系统偏好设置主题 class，不再闪
- **关于区新增 OpenTerminal 推荐链接**（`billowliu2.github.io/OpenTerminal`），与 KimiSwitch 官网、Kimi Eyes 插件站并列
- models.dev 快照同步至 2026-10-15（8,873 模型 / 230 供应商），本次含 14 条模型价格调整与 3 条已下线模型清理
