# KimiSwitch v0.7.15

## 新功能

- **用量统计新增「昨天」选项卡**：时间范围现为 今天 / 昨天 / 7 天 / 30 天 / 全部，「昨天」按本地时区严格统计昨日 0 点至今日 0 点（不渗入今天），顶部概览卡同步扩展为 5 张
- **新增「模型用量统计」趋势选项卡**：在「供应商模型用量趋势」之后，不按天、跨供应商按模型名汇总（同一模型经不同供应商合并为一行），横向条形图按 Token 降序，悬停显示请求数 / Token / 缓存命中 / 费用；子代理模型仍单独成行

## 修复

- **opencode Go 套餐子代理请求 400**：Go 网关（opencode.ai/zen/go）近期强制要求 `x-opencode-session` 请求头用于路由与提示词缓存，缺失即 400 拒绝。现在导出配置时，凡指向 Go 端点的供应商会自动补写 `custom_headers.x-opencode-session`（已有用户自定义值保留不覆盖）；按量计费的 `zen/v1` 端点不受影响
- 定价测试基准条目更新：models.dev 上游下架 `moonshotai/kimi-k2.5` 官方条目，测试基准切换到 `moonshotai/kimi-k3`

## 数据

- models-dev 快照同步至 2026-09-09（7583 模型 / 213 供应商），并补齐 `public/` 前端静态目录（原停留在 08-27）
